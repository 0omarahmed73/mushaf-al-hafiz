# G1: does Flutter web's FontLoader accept QUL's original WOFF2 and draw the same glyphs as the TTF?

| Field | Value |
|---|---|
| Gate | G1 (research D3, «Early gates») |
| Date | 2026-11-21 |
| Command | `python3 tool/web_smoke/gate_g1_woff2.py $GATES/g1_fontloader --work $GATES/g1_work --url http://127.0.0.1:8765` (probe app in the scratchpad `$GATES/g1_fontloader/`, outside the repository; Flutter 3.50.0, Dart 3.14.0). The probe fetches the font bytes with `fetch`, registers them with `FontLoader(family)..addFont(bytes)` (the same call `PageFontLoader` makes), and draws the first 8 ayah lines of the page from `assets/mushaf/pages/*.json` |
| Engines | Chromium (headless, playwright-core with the cached chromium-1255), twice: **CanvasKit** (normal JS build) and **skwasm** (`--wasm` build); the renderer actually used was read from the requests (`canvaskit` and `skwasm` respectively). Firefox: **not run** (no engine installed, no download approved, T002). WebKit: **not run** (same) |
| Inputs | (a) QUL's original `data-raw/qul/x-font-qpc-v2-woff2/p{1,2,50}.woff2`, byte for byte; (b) the app's `assets/fonts/qpc-v2/p{1,2,50}.ttf` |
| Measured numbers | WOFF2 vs TTF, pages 1, 2, 50, 412x700 screenshots (288,400 pixels each): **0 differing pixels** in CanvasKit and **0** in skwasm (the PNG files are even byte-identical). CanvasKit vs skwasm: **0 differing pixels** for all six renders. Ink (non-white pixels) 20,788 / 21,999 / 34,627 for pages 1 / 2 / 50 in every one of the 12 renders, so none is blank. No console error, no page error. A look at the page-1 render shows the Fatiha with its ayah-number rosettes, as expected |
| Size of the whole Mushaf | the 604 WOFF2 files: 97,748,500 bytes; the 604 TTF files: 159,004,392 bytes; page JSON (`assets/mushaf`): 3,792,807; ayah data (`assets/ayah`): 9,382,857. Whole Mushaf with WOFF2 = **110,924,164 bytes (110.9 MB, 105.8 MiB)**; with TTF = 172,180,056 bytes (172.2 MB) |
| Verdict | **PASS** (Chromium; Firefox and WebKit not run) |
| Consequence for the plan | `fontExtension = woff2`: the web serves QUL's original WOFF2 byte for byte (no conversion, sha256 against `data-raw`, research D3 first branch). The download button label and the manifest sizes use about 110.9 MB (computed from `pack.json`, not typed). If a later check finds a browser that rejects WOFF2, the fallback is the TTF route (172.2 MB) and the converted copies of the owner's spike; this does not change the code, only the extension constant |
