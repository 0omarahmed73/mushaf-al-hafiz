# G7: do Cairo, Amiri Quran and Reem Kufi cover every code point the web build can show?

| Field | Value |
|---|---|
| Gate | G7, font coverage of the bundled fonts (research D7) |
| Date | 2026-11-21 |
| Command | `uv run --offline --with fonttools python tool/web_font_coverage.py` (test: `cd tool && uv run --offline --with fonttools --with pytest pytest test_web_font_coverage.py -q`, 7 passed) |
| Engines | not a browser gate; reads the `cmap` of the six font files (Cairo Regular, Medium, SemiBold, Bold, Amiri Quran, Reem Kufi) |
| Scope | Dart string literals under `lib/` (without `lib/pdf` and `lib/render`, which the web build does not contain) plus every string of `assets/ayah/{text,tafsir,translation,gharib}`: 178 distinct code points; control and format characters (U+200C/D/E/F and the like) need no glyph and are ignored |
| Measured numbers | gaps: **1 code point, U+065E ARABIC FATHA WITH TWO DOTS**. It is in `assets/ayah/text/*.json` (1,807 occurrences in 757 distinct words, 96 of the 114 surah files, for example «ءَايَةٞ», «غِشَٰوَةٞ») and in 4 places of `lib/search/search_trace.dart` (a copy of Quran text). Not in Amiri Quran, Reem Kufi or Cairo (checked directly in each cmap). Checked as an extra: the Arabic strings of `contracts/ui.md` and `spec.md` add no further gap (the arrows U+2190 and U+2192 appear only in the design prose, not in any app string; the on-screen arrows are icons) |
| Verdict | **FAIL** (one gap) |
| Consequence for the plan | The ayah sheet and the search rows draw the Quran text with `AmiriQuran` (`lib/mushaf/mushaf_page.dart` `kQuranFont`). On Android a system font supplies U+065E; on the web with no system font and no third-party host the mark would be missing or drawn as an empty box. The Mushaf page itself (QCF page fonts) is not affected. Research D7 says: the plan returns to the owner with the exact code point; a font that has it would be a **new licence entry** (D8). Candidates to check, not downloaded here: an OFL font with the Quranic annotation block (for example Scheherazade New or Noto Naskh Arabic). Until the owner decides, the fallback list of `main_web.dart` stays `Cairo, AmiriQuran, ReemKufi`, and the audit/smoke must treat any request for another font host as a failure |
| Owner decision needed | choose between (a) adding one OFL font that has U+065E to the web build only (licence row, size about 0.2 to 0.5 MB), (b) leaving the mark off in the web ayah sheet (changes Quran text rendering, Principle I: not recommended), (c) accepting an empty box. Recommended: (a) |
